# 📊 Dashboard de Monitoramento de Patrimônio e Planejamento para Portugal

Este projeto consiste num dashboard interativo desenvolvido no **Power BI** para auxiliar no planeamento financeiro estratégico e na mudança de residência para Portugal. O objetivo principal é consolidar ativos, projetar rendimentos e gerir o património considerando a conversão cambial (BRL / EUR).

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
- **Power BI Desktop**: Construção do modelo de dados e visualizações interativas.
- **Power Query**: Limpeza, tratamento e transformação de dados (remoção de cabeçalhos textuais e conversão de tipos).
- **DAX (Data Analysis Expressions)**: Criação de medidas calculadas para KPIs de patrimônio atual e projetado.
- **Excel / Base de Dados**: Estruturação inicial da tabela `Resumo_Planejamento`.

---

## 📈 Principais Funcionalidades do Dashboard
1. **Cartões de KPIs (Cartões de Indicadores):** Exibição do patrimônio atual e projetado, segmentado em Reais (BRL) e Euros (EUR) com base na cotação de referência.
2. **Gráfico de Rosca / Pizza Interativo:** Distribuição percentual dos valores por **Origem** (rendas, reservas de emergência, venda de bens antes da mudança, etc.).
3. **Tratamento de Dados Robusto:** Higienização de colunas com mistura de texto e valores numéricos utilizando o Power Query para garantir a integridade dos cálculos.

---

## 🚀 Como Executar o Projeto
1. Certifique-se de ter o **Power BI Desktop** instalado.
2. Faça o download do arquivo `.pbix` disponível neste repositório.
3. Abra o arquivo no Power BI para explorar os visuais, medidas DAX e a estrutura de dados.
